=============================================================
mini_E-commerce Platform - Complete Setup Script & Instructions
=============================================================

This document provides step-by-step instructions to set up the Backend, Frontend (Web), and Mobile app for local development.

-------------------------------------------------------------
1. PREREQUISITES
-------------------------------------------------------------
Ensure you have the following installed on your machine:
- Node.js (v18 or higher recommended)
- npm or yarn
- MongoDB (running locally or Atlas URI)
- Redis (running locally or a cloud instance)
- Angular CLI (`npm install -g @angular/cli`)
- Expo CLI (`npm install -g expo-cli` or use `npx expo`)

-------------------------------------------------------------
2. BACKEND SETUP (Node.js + Express)
-------------------------------------------------------------
1. Navigate to the Backend directory:
   cd Backend

2. Install dependencies:
   npm install


4. Run the Backend server (Development mode):
   npm run dev

   (The backend should now be running on http://localhost:3000)

-------------------------------------------------------------
3. FRONTEND SETUP (Angular Web App)
-------------------------------------------------------------
1. Open a new terminal and navigate to the Frontend directory:
   cd Frontend/mini-E-commerce

2. Install dependencies:
   npm install

3. Run the Angular development server:
   ng serve

   (The web app should now be running on http://localhost:4200)

-------------------------------------------------------------
4. MOBILE APP SETUP (Expo / React Native)
-------------------------------------------------------------
1. Open a new terminal and navigate to the Mobile app directory:
   cd Mobile/mini-E-mobile

2. Install dependencies:
   npm install

3. Environment Variables (if needed):
   Ensure your API URL points to your local backend. If testing on a physical device, 
   update the base URL in `constants/baseUrl.ts` (or similar config file) from `localhost` 
   to your computer's local IP address (e.g., `http://192.168.1.x:3000/api`).

4. Start the Expo development server:
   npx expo start --clear

   - To run on Android emulator: Press 'a'
   - To run on iOS simulator: Press 'i'
   - To run on physical device: Scan the QR code with the Expo Go app.

=============================================================
Troubleshooting
=============================================================
- Redis/MongoDB errors: Ensure your local Redis and MongoDB services are running before starting the backend.
- Mobile Network Errors: If the mobile app cannot connect to the backend, make sure you are using your machine's local IP address (not localhost) for the API URL when testing on a physical device or Android emulator.
